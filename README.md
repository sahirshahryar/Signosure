## Signosure

**cynosure** (n.): the North Star, a guiding light, or the center of
attention.

Signosure is the third-generation sign language data collection toolkit for
the Georgia Tech Center for Accessible Technology in Sign (GT-CATS).
It provides a unified, end-to-end system for the main tasks of collecting
new sign-language datasets:

* Collecting labeled data
* Processing videos (trimming, re-encoding, extracting features)
* Annotating and reviewing videos
* Visualizing data for faster review and debugging

It is an open-source system that can be deployed to a university cluster
or into a cloud platform like GCP.
